Spec strip & honesty panel

The last two blocks before the footer. The strip is for people who want to know what it is built out of; the panel is for the things a personal project has to say out loud.

Under the hood

Framework
Flutter 3.44 — one codebase for iOS, Android, Windows and Android TV
Playback
libmpv via media_kit — chosen because it exposes audio and subtitle tracks with their language tags
Sources
Xtream Codes player_api.php, or M3U with an optional XMLTV guide
Storage
SQLite via drift, indexed for large catalogues · credentials in the platform keychain
State
Riverpod, over repositories the UI can't see past — no screen knows whether it is talking to Xtream or M3U
Sync
Optional Laravel API with Sanctum tokens · last-write-wins on UTC timestamps
Artwork
Provider posters first, gaps filled from TMDB

What it isn't

Worth saying plainly

  • A player, not a service. It ships no channels and no content. You point it at a line you already have.
  • You won't find it in a store. Players that connect to IPTV panels get rejected, so it is built for sideloading — which is also why it isn't for sale.
  • It's a personal project. Built for one household, in the open, with no roadmap promises and no support desk.

Rules. The honesty panel is the only place --error appears on the site, and it carries no button. Specs are written as sentences with a reason attached where there is one — a bare list of package names tells a visitor nothing.
