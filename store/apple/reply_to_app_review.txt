Thank you for reviewing Dawn Player and for explaining the concern under Guideline 4.3(a). We have reworked the app in this build so that it is first and foremost a player for the user's own video files, and we have attached a screen recording from a physical iPhone that shows the points below, starting from launch.

What is distinct about Dawn Player, and what changed in this build:

- Plays the user's own video files. Dawn Player is now registered for common video types, so a video opens directly from the Files app or the share sheet, in place and without copying. "Open a video file" is the first option on the first screen.
- Resume that survives restarts. Every video, including a file opened from Files, reopens at the exact position where the user stopped, even after the app is closed; part-watched videos are collected in Continue Watching.
- Remembers audio and subtitle language. The language the user picks is selected automatically on every later video that has it, and an external .srt or .ass subtitle file can be loaded and is remembered for that video.
- A different playback engine. Dawn Player uses libmpv rather than the system player, so it plays MKV, HEVC, MPEG-TS and HLS with multiple audio and subtitle tracks, with adjustable audio sync.
- A simpler, file-first experience. Sign-in to a server is now the last of three options and is labelled "Media server". The Live tab appears only when a source the user added contains live streams.
- A new demo that needs no login. The review notes contain a single playlist link with two Creative Commons films, one as an HLS stream and one as an MKV file with several subtitle languages, both hosted by us.

Dawn Player includes no content, has no account system, and contains no ads or tracking.
